======== PipMint_Batch_01_Generic_Mana_0-9 ========
PipMint Mana Pips | Batch 01: Generic 0-9
Contents: mana_generic_0.png through mana_generic_9.png
Image size: 1024 x 1024 px; PNG RGBA; alpha=0 outside each pip
Pip designs normalized for consistent bounding circles and margins.
PNG print-resolution metadata: 600 DPI.
Transparent black RGBA pixels outside the pip are intentional.
These are custom approximations of classic MTG-style generic mana pips, not official source artwork.
